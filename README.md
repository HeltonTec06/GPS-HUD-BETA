# GTA GAME GPS V17

Beta de teste do GPS gamer com tema GTA San Andreas.

## GitHub Pages

1. Suba os arquivos deste pacote para um repositório.
2. Em **Settings → Pages**, selecione a branch/pasta publicada.
3. Abra o endereço HTTPS gerado pelo GitHub Pages.

O GPS do navegador exige HTTPS e permissão de localização.
